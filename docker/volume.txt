volume: là nơi lưu trữ dữ liệu của container. Nhiều container có thể mount đến 1 volume. một container cx mount đến nhiều volume

Có 2 cách lưu trữ dữ liệu bền vữngcho Container

Cách 1: Named volume
docker volume create app-1-volume
//Gắn vào volume
docker run -d -it --name app-1 -v app-1-volume1:/folder_a -v app-1-volume2:/folder_b -p 8080:80 alpine: tự tạo volume luôn, tạo folder tương ứng trên alpine luôn

Tiếp theo tạo app-2 nhưng mount volume kia;

vandz@ecommerce:~$ docker run -d -it --name app-2 -v app-1-volume1:/folder_c -v app-1-volume2:/folder_d -p 8081:80 alpine

/folder_c # cat /folder_c/a.txt

/folder_c # cat /folder_d/b.txt
Hello cậu b


Cách 2: Bind mount: Ánh xạ trực tiếp một đường dẫn thực tế có sẵn trên Host Machine vào Container.

docker run -d -it --name app-3 -v $(pwd)/datas:/folder_a -v  -p 8082:80 alpine

vandz@ecommerce:~$ sudo su
[sudo: authenticate] Password:
root@ecommerce:/home/vandz# echo "Hello" >> datas/a.txt
root@ecommerce:/home/vandz# groups docker exec -it app-3 sh^C
root@ecommerce:/home/vandz#  docker exec -it app-3 sh
/ # cat /folder_a/a.txt
Hello
