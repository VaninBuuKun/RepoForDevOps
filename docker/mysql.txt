docker run -d \
  --name my-mysql \
  -p 3306:3306 \
  -e MYSQL_ROOT_PASSWORD=secret \
  -v mysql_data:/var/lib/mysql \
  mysql:8.0

-d: Chạy ngầm container.
--name my-mysql: Đặt tên container là my-mysql.
-p 3306:3306: Mở port 3306 để kết nối từ bên ngoài.
-e MYSQL_ROOT_PASSWORD=secret: Đặt mật khẩu root là secret (bạn có thể đổi thành mật khẩu khác).
-v mysql_data:/var/lib/mysql: Gắn volume để giữ lại dữ liệu, không lo mất database khi xóa container.

docker exec -it my-mysql mysql -u root -p : chạy xong sẽ nhập mật khẩu root (-p nghĩa là đăng nhập bằng password)

Lưu ý docker exec sẽ tạo một tiến trình bên trong container, sau tên container sẽ là lệnh đầu tiên thực hiện sau khi vào container;
có thể dùng:
docker exec -it my-mysql bash
để vào môi trường dòng lệnh của linux rồi gõ: mysql -u root -p cũng cho ra kq tương tự -> mysql là một cái chương trình dòng lệnh đã có sẵn trong container.
