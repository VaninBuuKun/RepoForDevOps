** B1. Cài môi trường runtime .Net.
1. Tải và chạy script cài đặt .NET 9.0 Runtime

Bash
# Tải script từ Microsoft
wget https://dot.net/v1/dotnet-install.sh -O dotnet-install.sh
chmod +x ./dotnet-install.sh

# Cài đặt ASP.NET Core Runtime 9.0 vào hệ thống
sudo ./dotnet-install.sh --runtime aspnetcore --version 9.0.0 --install-dir /usr/share/dotnet
2. Tạo Symlink để toàn bộ hệ thống nhận lệnh dotnet

Bash
# Tạo liên kết lệnh dotnet vào /usr/bin
sudo ln -sf /usr/share/dotnet/dotnet /usr/bin/dotnet
3. Kiểm tra lại kết quả

Bash
dotnet --list-runtimes

Chạy như này. ASPNETCORE_ENVIRONMENT=Development dotnet Identity.Api.dll.

nano /etc/systemd/system/identity.service

[Unit]
Description=My Identity Service
After=network.target docker.service //Docker khởi động, xong mình ms chạy
Wants=docker.service //Nếu service này khởi động thì kích hoạt docker khởi động.

[Service]
Type=simple
User=vandz
WorkingDirectory=/home/vandz/lab2_identityServer
ExecStart=/usr/bin/dotnet Identity.Api.dll
Environment=ASPNETCORE_ENVIRONMENT=Development

# Tự động restart khi crash
Restart=always
RestartSec=5s

[Install]
WantedBy=multi-user.target //Sau khi systemctl enable identity thì nó đưa service này vào danh sách các service sẽ khởi động cùng lúc với server
# 1. Reload lại systemd để nhận file mới
sudo systemctl daemon-reload

# 2. Cho phép service tự bật khi boot VPS & chạy ngay lập tức
sudo systemctl enable --now identity-api

# 3. Kiểm tra trạng thái
sudo systemctl status identity-api

# 4. Xem log realtime của app
sudo journalctl -u identity-api -f
